### MCP Servers

I have been experimenting with local MCP with Visual Studio Code to Azure DevOps. There is a GitHub repository which provide clear instructions for installation: https://github.com/microsoft/azure-devops-mcp. 

It is easy to setup following the guide and you'll be quickly able to conenct to your Azure DevOps project, and start querying away.
