# AI Experiements

This page is about the different experiementations with AI

### MCP Servers

I have been experimenting with local MCP with Visual Studio Code (with CoPilot) and Azure DevOps. There is a GitHub repository which provide clear instructions for installation: https://github.com/microsoft/azure-devops-mcp. 

The installation is straightforwards and in no time you will be connected to Azure DevOps, and begin any queries. I was satisfied this was now configured and thought I would carry on experimenting another time. However, when I went to start this again it would not connect to Azure DevOps. There is a helpful troubleshooting section that can assist, unfortunately I had to resort to hard coding the PAT token into the JSON configuration file. This is not committed into Git. 

![MCP Hard Coded Template](/assets/images/mcp/hard_coded_mcp_pat.png)

With the PAT token I can start the session multiple times without fail. I've created a simple project in Azure DevOps with User Stories which includes Azure resources deployed with Terraform and a simple Python application. This is inspired from Microsoft documentation of a deployment of a Python application but with Terraform.

![MCP Hard Coded Template](/assets/images/mcp/basic_tasks_mcp.png)

Lets see if it works by querying those tasks

![MCP Hard Coded Template](/assets/images/mcp/list_workitems_mcp.png)

If I were to list the tasks within those User Stories the list would appear just like the above screenshot. Not lets put a User Story into the first sprint. 

![MCP Hard Coded Template](/assets/images/mcp/sprints_created_mcp.png)

What is interesting is I did not have the tools such as Azure CLI installed for the sprints to be created. A CURL request with the PAT token from earlier was used to create those items. Now I'm feeling lazy lets see if this can create the code for me and setup a repository. 

These are some dummy tasks I've created.

![MCP Hard Coded Template](/assets/images/mcp/user_story_and_tasks_mcp.png)

I will now request for code to be created from the User Stories from the associated tasks.

![MCP Hard Coded Template](/assets/images/mcp/deploy_code_short_output.png)

It has created boilerplate code and a directory it thinks is correct. There are no details in the User Story or tasks so it just created a base which can be build upon on. On first inspection it requires a thorough review. 

![MCP Hard Coded Template](/assets/images/mcp/files_created_mcp.png)

If the requirements were clearer the outputs would be more tailored, this is the start of the capability offered by MCP. As always details instructions are required to meet the requirements but always review the outputs.
